Create a scheduled prompt.

Use a standard five-field cron expression in the machine's local time: minute hour day-of-month month day-of-week. The prompt is enqueued as a visible user message only when the agent loop is idle; it never interrupts a turn. Recurring jobs default to true and automatically expire after 7 days, firing their final matching prompt before deletion. Set recurring=false for a one-shot: it fires at the next match and then auto-deletes. Set durable=true only when the job must survive process/session restart; the default durable=false keeps it in memory for this session only. Durable missed one-shots are surfaced as soon as the resumed session is idle for catch-up. Avoid :00 and :30 when practical to prevent many jobs herding on the same minute. Keep prompts self-contained because they run later. Return the job id from this call for cron_delete.

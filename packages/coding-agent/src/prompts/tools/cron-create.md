Create a scheduled prompt.

Use a standard five-field cron expression in the machine's local time: minute hour day-of-month month day-of-week. When it fires during an active turn the prompt is delivered as a system notification folded in after your next completed tool call; it never interrupts the in-flight tool call, never waits for interactive input, and is never a user message. When it fires while idle it wakes a turn with the same system notification. Recurring jobs default to true and automatically expire after 7 days, firing their final matching prompt before deletion. Set recurring=false for a one-shot: it fires at the next match and then auto-deletes. Set durable=true only when the job must survive process/session restart; the default durable=false keeps it in memory for this session only. A durable one-shot whose time passed while the process was down is scheduled for immediate catch-up when the session resumes. Avoid :00 and :30 when practical to prevent many jobs herding on the same minute. Keep prompts self-contained because they run later. Return the job id from this call for cron_delete.
